# Gradus

个人课程与学分管理前端，使用 React、TypeScript、Vite。配色参考 Prism，排版参考 letters。

## 运行

需要 Node.js 22.12 或更新版本以及 pnpm。

```sh
pnpm install
pnpm dev
```

```sh
pnpm build
pnpm test
```

## 数据

- 培养计划：用户提供的《2025 金融学（量化金融）专业培养计划》，共 9 页。
- 毕业学分 157.5，第二课堂 6 学分单独统计。
- 初始学期名称采用用户指定的“27 第一学期”，包含课表中匹配培养计划的 11 门课程，共 26 学分。
- 课表中的“体育”按培养计划二年级第一学期对应体育Ⅲ，可编辑。
- 课程页面仅显示课程名称、学分与复习资料是否存在。学分页面独立维护已修记录。
- 全部资料使用 IndexedDB 保存；数据与设置提供 ZIP 完整备份和恢复。
- 当前使用设备和浏览器决定数据保存位置，清除网站数据会删除本地记录。建议导出备份。
- 当前前端独立运行；FastAPI、SQLite 后端尚未接入。

培养计划课程集中在 `src/curriculum.ts`，学期和资料持久保存逻辑位于 `src/store.ts`。
